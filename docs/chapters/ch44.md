# 第 44 章 屋顶线模型分析

## CUDA GPU并行编程：屋顶线模型分析

## 引言：性能评估的核心目标

本章将深入讲解**屋顶线模型（Roofline Model）**。这是GPU高性能计算中至关重要的性能分析工具，其核心目的在于：

1. 科学评估应用程序的性能瓶颈；
2. 判定应用属于**计算受限（Compute-Bound）**还是**内存受限（Memory-Bound）**；
3. 基于分析结果选择正确的优化路径。

在进行屋顶线分析之前，建议先掌握GPU硬件架构参数（如总线速度、显存带宽、指令吞吐量等）的基础知识。只有理解了这些底层指标，才能准确解读分析结果。例如，在之前的向量规约（Vector Reduction）案例中，我们采用了共享内存、合并访问和Shuffle操作等优化手段，正是因为通过屋顶线分析确认了该应用是典型的*内存受限*应用。

## 关键性能指标与算术强度

## 峰值性能参数

评估性能需对比实测值与硬件理论峰值。以NVIDIA Ampere架构（A100）为例：

- FP32（非Tensor Core）：19.5 TFLOPS
- FP64：9.7 TFLOPS
- INT32：19.5 TOPS

- **显存带宽峰值（Peak Memory Bandwidth）**：约 1.5 TB/s（即 1500 GB/s）。
- **计算吞吐量峰值（Peak Compute Throughput）**：

**注意**：仅凭单一指标（如达到1 TB/s带宽）无法判断性能优劣。高带宽可能源于过多的内存操作而缺乏有效计算。我们需要一个综合指标来平衡二者。

## 算术强度（Arithmetic Intensity, AI）

算术强度是屋顶线模型的核心度量，定义为每字节内存访问所执行的浮点运算次数：

> AI = (指令吞吐量 (FLOPS/s)) 内存带宽(Bytes/s) [单位: FLOP/Byte]

- **高AI**：计算量远大于数据搬运量 → 倾向于计算受限。
- **低AI**：数据搬运量远大于计算量 → 倾向于内存受限。

## 可达性能公式

应用程序的可达性能（Attainable Performance）受限于硬件峰值和当前算术强度下的带宽上限，取二者最小值：

> Performance = min ( Peak Compute , AI × Peak Bandwidth )

该公式构成了屋顶线图的数学基础：当 AI × Bandwidth < Peak Compute 时，性能随AI线性增长（内存墙）；反之则达到平台期（计算墙）。

## 屋顶线图解读与转折点

## 坐标轴定义

- **X轴（对数坐标）**：算术强度（AI），单位 FLOP/Byte。
- **Y轴（对数坐标）**：性能，单位 GFLOPS 或 TFLOPS。

## 转折点（Ridge Point）

转折点是内存受限区与计算受限区的分界点，对应硬件同时达到带宽峰值和计算峰值的状态：

> AI<sub>ridge</sub> = (Peak Compute(FLOPS/s)) Peak Bandwidth (Bytes/s)

以A100 FP32为例：AI<sub>ridge</sub> = 19500 / 1500 =1 3 FLOP/Byte。

- **左侧区域**（AI < AI<sub>ridge</sub>）：**内存受限区**。优化重点：合并访问、共享内存、L1/L2缓存利用率、预取。
- **右侧区域**（AI > AI<sub>ridge</sub>）：**计算受限区**。优化重点：指令级并行、消除依赖、Fast Math、Tensor Core、寄存器优化。

## 多级存储屋顶线

实际分析中需区分不同存储层级，因其带宽差异巨大：

- **DRAM Roofline**：使用全局显存峰值带宽（最常用基准）。
- **L2 Cache Roofline**：使用L2缓存峰值带宽（转折点右移）。
- **L1/Shared Mem Roofline**：使用L1/SMEM峰值带宽（转折点进一步右移）。

同一应用在DRAM层面可能是内存受限，但在L1层面可能已进入计算受限区。优化目标是将数据点向右上方推移，逼近或超越转折点。

## 实战案例：向量规约的屋顶线分析

## 基准版本分析

使用Nsight Compute对向量规约基准版本（01\_reduce）进行分析：

```bash
nvcc -O3 -o reduce_01 reduce_01.cu
ncu --launch-mode profile ./reduce_01
```

在Nsight Compute的“Roofline”面板中选择“FP32(Non-Tensor)”视图。对于RTX 3060等消费级卡，转折点AI约为30FLOP/Byte。基准版本的实测点位于转折点**左侧远处** （AI≈0.12），确认为严重内存受限。

## 优化版本对比

对优化版本（03\_reduce\_shared\_unroll）进行相同分析：

- **基准版**：AI = 0.12 FLOP/B, 性能 ≈ 15 GFLOPS
- **优化版**：AI = 0.66 FLOP/B, 性能 ≈ 177 GFLOPS

**分析结论**：

1. 算术强度提升约 **5.5倍**（0.66 / 0.12）；
2. 绝对性能提升约 **11.8倍**（177 / 15）；
3. 数据点在屋顶线图中显著向右上方移动，但仍处于转折点左侧，说明仍有内存优化空间（如后续Shuffle优化可进一步提升AI）。

## 总结与优化策略指引

屋顶线模型为GPU性能优化提供了量化导航：

| 区域 | 特征 | 推荐优化手段 |
| --- | --- | --- |
| 内存受限区 | AI < Ridge Point | 合并访存、Shared Memory、向量化加载、 |
